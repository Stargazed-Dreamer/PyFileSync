# PyFileSync 主配置文件示例
# ============================================================
# 复制本文件为 main_config.txt 后编辑。main_config.txt 已在 .gitignore 中。
#
# 格式说明：
#   - 顶行以 *YYYY.MM.DD HH:MM:SS 表示时间戳（用于"跳过早于时间戳"增量备份）
#     备份成功后时间戳会自动更新为当前时间
#   - 路径对使用 -> 或 → 分隔
#   - 路径对后可跟 | 分隔的元数据（顺序不限）：
#       |重复文件:覆盖|跳过|检查日期和大小   （默认覆盖）
#       |增删文件处理:增量更新|完全同步       （默认增量更新）
#       |状态:启用|禁用                       （默认启用）
#   - 过滤规则行以空格缩进，❌ 表示排除，✔ 表示包含（作为排除例外，优先级高于排除）
#   - 过滤规则支持相对路径（相对于源目录）和绝对路径（带盘符或 / 开头）
#   - # 起始的行视为注释
# ============================================================

*2025.01.01 00:00:00

# 示例 1：增量更新 + 检查日期和大小（推荐日常使用）
C:/Users/your_name/Documents -> D:/Backup/Documents |重复文件:检查日期和大小 |增删文件处理:增量更新
  ❌ tmp
  ❌ cache
    ✔ keep_this.log

# 示例 2：完全同步（删除目标侧多余文件，镜像源目录）
C:/Users/your_name/Pictures -> D:/Backup/Pictures |重复文件:检查日期和大小 |增删文件处理:完全同步
  ❌ Thumbs.db

# 示例 3：覆盖模式（不检查直接覆盖）
E:/Projects -> F:/Archive/Projects |重复文件:覆盖

# 示例 4：跳过模式（目标已存在则跳过）
C:/Users/your_name/Downloads -> D:/Backup/Downloads |重复文件:跳过 |状态:启用

# 示例 5：使用 → 箭头分隔（与 -> 等价）
C:/Users/your_name/Music → D:/Backup/Music

# 示例 6：禁用某条规则（保留配置但不执行）
C:/Users/your_name/Videos -> D:/Backup/Videos |状态:禁用
